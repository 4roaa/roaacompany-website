# Roaacompany Website (2026)
### Digital Solutions Built Around Business | حلول رقمية تبدأ من احتياج العمل

موقع إلكتروني تعريفي واستشاري احترافي، متطور، سريع ومتجاوب بالكامل لشركة **Roaacompany** للحلول الرقمية والتقنية الإبداعية بالمملكة العربية السعودية.

---

## 🌟 المميزات والمواصفات الفنية

1. **دعم ثنائي اللغة كامل (Bilingual RTL / LTR):**
   - اللغة العربية (RTL) متوافقة بطبيعتها مع خط `IBM Plex Sans Arabic`.
   - اللغة الإنجليزية (LTR) متوافقة بطبيعتها مع خط `Manrope`.
   - تبديل فوري للغة وتوجيه الصفحة مع حفظ التفضيل محلياً (`localStorage`).

2. **أقسام الموقع الشاملة:**
   - **الرئيسية (Home):** واجهة استعراضية تفاعلية لهوية الشركة ونموذج القدرات الثلاثي (Design • Build • Grow) مع خلفية الوشاح الرقمي وشبكة العقد الذكية.
   - **عن الشركة (About Us):** قصة الشركة، منهجية العمل، الرؤية، الرسالة، ووعدنا للعملاء.
   - **الخدمات (Services):** تفصيل دقيق للمجموعات الثلاث (التجربة الرقمية، حلول الويب والتقنية، الدعم الرقمي والنمو).
   - **الحلول التقنية (Technology Solutions):** ٧ بطاقات متخصصة (بوابات، لوحات تحكم، مسارات عمل، نماذج متقدمة، تقارير، تكاملات، حلول مخصصة) مع أمثلة واقعية.
   - **القطاعات (Industries):** ٥ قطاعات استراتيجية مع المخرجات الرئيسية لكل قطاع.
   - **طريقة العمل (How We Work):** مسار تفاعلي من ٦ مراحل (نفهم، نحدد، نصمم، نطوّر، نطلق، نطوّر ونحسّن) ومبادئ الشراكة.
   - **تواصل معنا (Contact Us):** نموذج طلب مشروع مفصل بالتحقق من الحقول، اختيار الميزانية، الموعد، وتحديد الخدمة، مع بطاقة معلومات مباشرة ورابط واتساب فوري.
   - **الصفحات القانونية:** سياسة الخصوصية والشروط والأحكام.

3. **هوية بصرية فخمة ومتزنة (No AI Slop / No Neon clichés):**
   - ألوان العلامة: كحلي عميق (`#0F172A`)، بنفسجي Roaa (`#7C3AED`)، أزرق رقمي (`#2563EB`)، ولمسة أخضر فاتح (`#B7F36B`).
   - خطوط طباعية متناغمة، بدون تدرجات لونية فجة، وتجربة قراءة مريحة جداً وفق معايير الوصول العالمية WCAG.

4. **تحسين محركات البحث والشبكات الاجتماعية (SEO & Social Cards):**
   - بيانات وصفية كاملة، OpenGraph، Twitter Card، وSchema.org JSON-LD مدمجة في `index.html`.

## 📁 هيكلية البيانات وكيفية التعديل (Centralized Data)

تم تصميم المشروع ليكون سهل التحديث من ملفات بيانات مركزية دون الحاجة لتعديل الأكواد البرمجية للواجهات:

- `src/data/company.ts`: بيانات الشركة الأساسية (الاسم، البريد الإلكتروني، رقم الواتساب، العنوان، الموقع).
- `src/data/services.ts`: قائمة الخدمات وقدرات التصميم والتطوير والدعم.
- `src/data/solutions.ts`: بطاقات الحلول التقنية وأمثلة الاستخدام.
- `src/data/industries.ts`: القطاعات ومخرجات الأعمال.
- `src/data/process.ts`: مراحل منهجية العمل ومبادئ الشراكة.
- `src/data/content-ar.ts` & `src/data/content-en.ts`: جميع النصوص ثنائية اللغة وترجماتها.

## 🚀 التشغيل المحلي (Local Development)

تأكد من وجود بيئة Node.js (الإصدار 18 أو أحدث) مثبتة على جهازك:

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير المحلي (Dev Server)
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 📦 بناء المشروع للإنتاج (Production Build)


سيتم إنشاء ملفات الويب الثابتة الجاهزة للنشر داخل مجلد `dist/`.

## 🌐 خطوات الرفع والنشر (Deployment Guide)

### 1. الاستضافة عبر Hostinger (أو أي استضافة cPanel / Shared Hosting):
1. قم بتنفيذ الأمر: `npm run build`
2. ادخل إلى لوحة تحكم **Hostinger hPanel** -> **File Manager** (مدير الملفات).
3. انتقل إلى مجلد `public_html`.
4. ارفع كافة محتويات مجلد `dist` مباشرة إلى داخل `public_html` (بحيث يكون ملف `index.html` في جذر `public_html`).
5. أنشئ ملف `.htaccess` داخل `public_html` بالمحتوى التالي لدعم توجيه SPA والـ Caching:
   ```apache
   <IfModule mod_rewrite.c>
     RewriteEngine On
     RewriteBase /
     RewriteRule ^index\.html$ - [L]
     RewriteCond %{REQUEST_FILENAME} !-f
     RewriteCond %{REQUEST_FILENAME} !-d
     RewriteRule . /index.html [L]
   </IfModule>
   ```

### 2. الاستضافة عبر Vercel:
1. ارفع المشروع إلى مستودع GitHub.
2. ادخل إلى **Vercel** واضغط **Add New Project**.
3. اختر المستودع وسيقوم Vercel تلقائياً باكتشاف Vite وضبط إعدادات البناء:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. اضغط **Deploy**.

### 3. الاستضافة عبر Netlify:
- **Build command:** `npm run build`
- **Publish directory:** `dist`
